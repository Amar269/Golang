# Topic 1: What is Go?

## What is Go?

Go (Golang) is a statically typed, compiled, general-purpose programming language
designed for building simple, efficient, reliable and concurrent software.

## Who created Go?

Go was created at Google by:

- Robert Griesemer
- Rob Pike
- Ken Thompson

## Important Characteristics

- Statically typed
- Compiled language
- Garbage collected
- Supports concurrency
- Simple language design
- Fast compilation
- Strong standard library
- Powerful developer tooling
- Cross-platform
- Well suited for backend and cloud development

## Where is Go commonly used?

- Backend APIs
- Cloud infrastructure
- Microservices
- Distributed systems
- Networking
- DevOps tools
- CLI applications
- Container and cloud-native systems

## Go and OOP

Go does not use traditional class-based OOP like C# or Java.

Instead, Go provides:

- Structs
- Methods
- Interfaces
- Embedding
- Composition
- Generics
